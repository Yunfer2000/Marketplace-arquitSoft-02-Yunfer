# Restricciones

| ID | Restricción | Descripción |
|---|---|---|
| RC01 | Aplicación web | El sistema debe ser accesible mediante un navegador web. |
| RC02 | Control de versiones | Los archivos del proyecto deben gestionarse con Git y mantenerse en un repositorio compartido. |
| RC03 | API REST | La aplicación web y el backend deben comunicarse mediante una API REST. |
| RC04 | Pasarela de pago | El sistema debe integrarse con una pasarela de pago externa. |
| RC05 | Servicio de envío | El sistema debe integrarse con un servicio externo para gestionar las entregas. |
| RC06 | Arquitectura en tres capas | El diseño inicial debe separar presentación, lógica de negocio y datos. |
| RC07 | Documentación en Markdown | Los documentos del laboratorio deben mantenerse en archivos Markdown dentro del repositorio. |
