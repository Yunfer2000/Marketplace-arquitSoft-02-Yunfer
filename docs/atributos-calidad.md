# Atributos de calidad

| ID | Atributo | Descripción |
|---|---|---|
| AC01 | Rendimiento | El sistema debe mantener tiempos de respuesta adecuados durante periodos de alta concurrencia. |
| AC02 | Seguridad | El sistema debe proteger los datos de usuarios y las operaciones de compra. |
| AC03 | Escalabilidad | El sistema debe soportar el incremento de usuarios y operaciones durante campañas comerciales. |
| AC04 | Mantenibilidad | La arquitectura debe facilitar el mantenimiento, evolución y modificación del sistema. |
| AC05 | Disponibilidad | El sistema debe mantenerse disponible para permitir la consulta del catálogo y la gestión de compras. |
