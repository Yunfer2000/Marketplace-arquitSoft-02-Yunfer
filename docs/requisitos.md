# Requisitos

## Requisitos funcionales

| ID | Requisito |
|---|---|
| RF01 | El sistema debe permitir registrar y autenticar usuarios. |
| RF02 | El sistema debe permitir gestionar productos del catálogo. |
| RF03 | El sistema debe permitir a los clientes consultar productos. |
| RF04 | El sistema debe permitir agregar productos al carrito. |
| RF05 | El sistema debe permitir gestionar pedidos. |
| RF06 | El sistema debe permitir procesar pagos mediante una pasarela externa. |
| RF07 | El sistema debe permitir gestionar la información de los envíos. |
| RF08 | El sistema debe permitir consultar el estado de los pedidos. |

## Requisitos no funcionales

| ID | Requisito |
|---|---|
| RNF01 | El sistema debe soportar un incremento de usuarios durante campañas comerciales. |
| RNF02 | El sistema debe mantener tiempos de respuesta adecuados ante alta concurrencia. |
| RNF03 | El sistema debe proteger los datos de los usuarios y las operaciones de compra. |
| RNF04 | El sistema debe mantener una estructura que facilite su mantenimiento y evolución. |
| RNF05 | El sistema debe utilizar una API REST para la comunicación entre frontend y backend. |
