# Necesidad del negocio

## Problema del negocio

Se desea desarrollar un marketplace de productos para mascotas, en el cual diferentes sellers puedan ofrecer sus productos y los clientes puedan realizar compras.

El sistema busca mejorar el proceso de compra de productos para mascotas, facilitar la participación de diferentes vendedores e integrar servicios externos relacionados con los pagos y los envíos.

## Objetivos del negocio

- Facilitar a los clientes la búsqueda y compra de productos para mascotas.
- Permitir que diferentes sellers puedan ofrecer y gestionar sus productos.
- Mejorar la experiencia de compra mediante un catálogo organizado y un carrito de compras.
- Integrar el proceso de pago mediante una pasarela externa.
- Facilitar la gestión y seguimiento de los pedidos y envíos.
- Contar con una plataforma que pueda evolucionar y mantenerse de manera organizada.
